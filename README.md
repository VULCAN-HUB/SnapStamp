# SnapStamp

> **⚠️ 미완성 / 작업 중 (BETA Ver-0.1)** — 기능은 동작하고 연속 사용 검증도 마쳤지만
> 아직 베타입니다. 실제 행사에 쓰기 전 반드시 사전 테스트를 거치세요.

행사장에 두면 참가자가 버튼 한 번으로 **인생4컷** 사진을 찍고, **QR 코드로 바로 받아 가는**
Windows 이벤트 포토부스 프로그램입니다. 설치 절차가 없고, 일반 USB 웹캠으로 동작합니다.

**사진은 인터넷으로 올라가지 않습니다.** 운영 PC 안의 로컬 서버로만 전달되므로 참가자의 초상이
외부 서버로 나가지 않고, 제작자에게도 어떤 정보도 전송되지 않습니다.

## 주요 기능

- **네 컷 촬영 → 자동 합성** — 카운트다운, 셔터 플래시, 완성 연출
- **QR 즉시 전달** — 손님 휴대폰으로 사진·움짤을 바로 다운로드. 인터넷 회선 불필요
- **움직이는 4컷(GIF/MP4)** — 셔터 직전 순간을 담아 인스타에 올리기 좋은 형태로 함께 제공
- **레이아웃 11종** — 세로 4컷 스트립, 2x2, 1x4, 상·하단 문구형, 아이돌 포토카드형 등. 드래그로 직접 조정 가능
- **브랜딩** — 배경색, 행사 문구(위치 9방향·pt 단위 크기), 로고, 날짜 표시
- **색감 6종 + 촬영 전 보정** — 원본/따뜻하게/차갑게/필름/비비드/흑백 + 밝기·대비·채도·선명도
- **손님 수령 페이지 꾸미기** — 배경색·글자색·로고·행사 문구를 운영자가 지정
- **Wi-Fi 접속 QR** — 현재 Wi-Fi 또는 PC 모바일 핫스팟 정보를 QR로 안내
- **부스 운영 편의** — 2단계 시작 동선, 방치 자동 복귀(남은 시간 예고), 저장 폴더에는 완성 사진과 움짤 2개만

## 다운로드

[Releases](../../releases) 에서 받으세요.

| 파일 | 설명 |
|---|---|
| `SnapStamp.zip` | **권장.** 압축을 풀면 `SnapStamp` 폴더 안에 `_internal` 폴더와 `SnapStamp.exe`가 있습니다. exe를 실행하세요. |
| `SnapStamp.exe` | 단일 파일 버전(편의용). 실행이 느리고 백신 경고 가능성이 더 높습니다. |

각 파일에는 `.sha256` 체크섬이 함께 있습니다. 무결성 확인에 쓰세요.

> **`_internal` 폴더를 지우거나 exe만 따로 옮기지 마세요.** 바탕화면에 두고 싶다면 exe를 옮기지 말고
> 마우스 오른쪽 → **바로 가기 만들기**로 단축 아이콘만 옮기세요.
> 압축 프로그램 안에서 바로 실행하지 말고 **폴더에 푼 뒤** 실행하세요.

### 최초 실행 시 경고

디지털 서명이 없어 Windows SmartScreen이 최초 1회 "Windows에서 PC를 보호했습니다"를 띄울 수 있습니다.
차단이 아니라 경고이며 **[추가 정보] → [실행]** 으로 통과됩니다.
**행사 당일 처음 실행하지 말고 전날 미리 한 번 실행해 두세요.**

## 요구 사항

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 이상 (64비트) |
| 카메라 | USB 웹캠(UVC 표준). 미러리스 + HDMI 캡처카드도 동일하게 인식 |
| 메모리 | 8 GB 이상 (16 GB 권장 — 움짤 인코딩에 여유) |
| 저장 공간 | 프로그램 약 340 MB + 사진(팀당 사진 1.7 MB + 움짤 1~5 MB) |
| 네트워크 | 손님 휴대폰이 접속할 Wi-Fi. **인터넷 회선은 불필요** |
| 관리자 권한 | 불필요 |

## 사용법

자세한 내용은 **[SnapStamp 실행 안내서 (BETA Ver-0.1).pdf](SnapStamp%20실행%20안내서%20(BETA%20Ver-0.1).pdf)** 를 보세요
(설치·설정·행사 운영·문제 해결, 실제 화면 포함).

간단히:

1. `SnapStamp.exe` 실행 → 카메라가 자동 연결됩니다.
2. **[설정]** 에서 레이아웃·브랜딩·색감·손님 페이지를 맞춥니다. 우측 미리보기에 즉시 반영됩니다.
3. **[촬영 시작]** → 손님 화면으로 전환됩니다.
4. 손님은 스페이스바(또는 USB 버튼)를 눌러 시작 → 한 번 더 눌러 촬영 → 네 컷 반복.
5. 완성 화면의 QR 두 개(① Wi-Fi 연결 → ② 사진·움짤 받기)를 찍어 받아 갑니다.

> QR 링크는 **프로그램이 켜져 있는 동안** 유효합니다. 받을 수 있는 사진 개수에 제한은 없지만,
> 프로그램을 종료하면 그때까지 나눠 준 링크가 모두 끊깁니다(사진 파일은 저장 폴더에 남습니다).

## 검증

- 연속 300회 세션 자동 테스트: 실패 0, 메모리 97~101 MB 평탄(누수 없음), 세션당 0.27 MB
- 실기 15세션 연속 촬영: 실패 0
- 전 회차 QR 재접속 + 사진 실제 다운로드 성공(267/267)

## 소스에서 빌드하기

```bash
pip install -r requirements.txt
python main.py                      # 개발 실행
```

```powershell
.\build_win.bat                     # onedir ZIP (배포 기본형)
.\build_win.bat -OneFile            # 단일 exe
.\build_win.bat -Both               # 둘 다
```

산출물은 `dist_out\` 에 생성됩니다. 다른 폴더에 두려면 `-OutDir <경로>` 또는 환경변수 `SNAPSTAMP_OUT`을 쓰세요.
빌드 끝에 Windows Defender 검사가 자동 실행됩니다. 백신 오탐 대응은 [docs/AV_FALSE_POSITIVE.md](docs/AV_FALSE_POSITIVE.md) 참고.

테스트:

```bash
python -m pytest -q
```

macOS 빌드는 [docs/MAC_BUILD.md](docs/MAC_BUILD.md) 참고(Mac 실기 필요).
